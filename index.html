Pomo: a study pet that grows when you focus

Oct 2026, SBU Hacks, team of four. Frontend and UI/UX lead

  • JavaScript
  • HTML/CSS
  • Web Serial
  • ESP32
  • Python

An ESP32 desk pet that hides the clock, notices when you drift to YouTube or TikTok, and only levels up when you actually study. Friends with their own Pomo earn a shared bonus, but only while everyone stays focused.

I designed and built the laptop dashboard: hand-drawn SVG nixie tubes, a punched time card for every session, a talking home screen, and live two-way sync with the device over USB and Bluetooth. The device owns the timer and XP, so the screen can never disagree with the pet on your desk.

What broke

Over Bluetooth on Windows, the dashboard said the device was on USB. Windows presents a paired Bluetooth device as a plain COM port with no IDs. Now a port only counts as USB if it reports a USB vendor ID.

Stock Portfolio Dashboard

June 2026, solo

  • Python
  • Streamlit
  • pandas
  • Plotly
  • yfinance

Tracks gain/loss, percent return, and total value across a portfolio. Three views: a holdings table, per-ticker returns, and a distribution view with sector allocation and a correlation heatmap.

The data layer and the Streamlit UI live in separate modules, and every push to GitHub redeploys the live app on Streamlit Cloud.

What broke

Embedded Digital Clock

Jan to Apr 2026, ESE 123

  • C
  • AVR assembly
  • ATmega4809
  • Soldering

I soldered and assembled the board, then wrote the firmware: a multiplexed seven-segment display, an RTC, 24-to-12-hour conversion, and button-driven hour and minute setting.

Writing C for a microcontroller was nothing like Python or Java. Every line drives the hardware directly.

What broke

The set-minutes loop got skipped whenever the button was still held from the last press. I fixed it by waiting for release before advancing state.
